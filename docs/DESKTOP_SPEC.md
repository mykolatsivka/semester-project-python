# DataLens Desktop — специфікація

## Формат програми

DataLens є нативною десктопною програмою для Windows. Вона запускається в
окремому вікні, не використовує вебсервер і не відкриває браузер.

## Основні функції

1. Відкриття CSV-файлів розміром до 25 MB з автоматичним визначенням роздільника
   та поширених кодувань.
2. Вбудований демонстраційний набір даних для швидкої перевірки програми.
3. Огляд таблиці, типів колонок, кількості рядків, пропусків і дублікатів.
4. Фільтрація за числами, категоріями, датами та текстом.
5. Розрахунок описової статистики й матриці кореляцій.
6. Побудова гістограм, box plot, scatter plot і стовпчикових діаграм.
7. Порівняння груп за агрегованими числовими показниками.
8. Експорт відфільтрованих даних у CSV.
9. Збереження метаданих аналізу в локальній базі SQLite.

## Технології

- Python 3.11+;
- PySide6 для нативного графічного інтерфейсу;
- pandas і NumPy для обробки та статистичного аналізу;
- Matplotlib для візуалізацій;
- SQLite для історії аналітичних знімків;
- PyInstaller для створення Windows EXE.

## Запуск

```powershell
.\.venv\Scripts\python.exe app.py
```

## Критерії готовності

- програма відкривається в окремому Windows-вікні;
- усі вкладки працюють без браузера та інтернет-з'єднання;
- CSV можна завантажити, проаналізувати, відфільтрувати й експортувати;
- автоматичні тести проходять успішно;
- код не містить залежностей або конфігурації вебверсії.
